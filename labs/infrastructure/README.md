# Infrastructure lab notebook

Status: planned; no infrastructure has been deployed by this repository.

Start with an isolated local VM lab. Record your chosen platform and actual results
in a copy of LAB-TEMPLATE.md. Do not place production hostnames or credentials here.

Suggested progression:
1. Define a disposable VM, network boundary and resource budget.
2. Manually provision it and document the exact steps and cleanup.
3. Inventory the guest using read-only commands appropriate to the selected OS.
4. Automate the repeatable setup and verify the observed result.
5. Destroy disposable resources and document the outcome.

Cloud or IaC examples can be added after selecting a provider and explicit scope.
This starter deliberately contains no apply/deploy commands or implied working lab.
